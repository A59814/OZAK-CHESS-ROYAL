# OZAK ROYAL CHESS — شطرنج ملكي ثلاثي الأبعاد (PWA)

## الهيكل
```
ozak-royal-chess/
├── index.html      الهيكل + محمّل المكتبات (يجرّب lib/three.min.js ثم CDN)
├── styles.css      واجهة زجاجية بإطارات ذهبية
├── game.js         محرك قواعد الشطرنج + الذكاء الاصطناعي (Minimax + Alpha-Beta) — بلا مكتبات
├── main.js         Three.js: المشهد السينمائي، اللوحة، القطع، الصوت، الفيزياء، الضباب، الواجهة
├── sw.js           Service Worker (يعمل دون إنترنت)
├── manifest.json   إعدادات PWA
├── icons/          أيقونات SVG و PNG
└── lib/            ضع هنا three.min.js (r128) للعمل دون إنترنت من أول تشغيل
```

## التشغيل
التطبيق يحتاج خادماً (لا يعمل بالنقر المزدوج على index.html لأن Service Worker يتطلب http/https):
```
cd ozak-royal-chess
python3 -m http.server 8080      # ثم افتح http://localhost:8080 (أو IP جهازك من الموبايل)
```
للنشر: ارفع المجلد كما هو إلى Netlify أو GitHub Pages أو Vercel (HTTPS)، ثم من الموبايل: "إضافة إلى الشاشة الرئيسية".

## للعمل دون إنترنت بالكامل
حمّل https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js وضعه في `lib/three.min.js`.
وإن لم تفعل، يحمّله التطبيق من CDN في أول تشغيل ويخزّنه Service Worker تلقائياً فيعمل بعدها دون اتصال.
(Stockfish.js اختياري للمستوى 100: المحرك المدمج يلعب بعمق 4 مع امتداد الكش وبحث السكون.)

## التحكم
- لمسة واحدة على قطعة ثم على الخانة المضيئة = تحريك.
- سحب بإصبع واحد = تدوير الكاميرا، إصبعان = تكبير وتحريك. زر ◎ يعيد الزاوية الافتراضية.
- ضباب الحرب (المستويات 80–100): ترى قطعك وما حول ملكك (3×3) فقط.
- النجوم: فوز = ★، فوز بأقل من 30 حركة = ★★، فوز دون خسارة أي قطعة = ★★★.
